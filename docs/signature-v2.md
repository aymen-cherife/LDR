# Signature format v2

Each value is encoded into a BLAKE2b digest with a 16-byte output, no key, salt or personalization. The digest is represented as lowercase hexadecimal. `+` denotes an incomplete structural read and `~` denotes a sketch. Existing status words keep their meaning.

All fixed-width numbers are little-endian. Lengths and counts are unsigned 64-bit integers. Text is UTF-8 with `surrogatepass`. Every tag below is one ASCII byte. A length-prefixed payload is the tag, an unsigned 64-bit byte length, then the bytes.

- None is `N`; booleans are `T` and `F`.
- Signed integers in the 64-bit range are `i` followed by eight two's-complement bytes. Other integers are `I`, a byte length and the shortest signed two's-complement representation.
- Floats are `f` and eight IEEE-754 bytes. All NaN bit patterns become `0x7ff8000000000000`. Signed zero is retained. Complex numbers are `c` followed by two such eight-byte float payloads.
- Strings use `s`, bytes `b`, and bytearrays `B`, each followed by its length-prefixed bytes. Temporary paths in strings are normalized before encoding.
- Lists `l`, tuples `t` and dictionaries `d` have a count followed by their elements. Dictionary keys and values are interleaved in insertion order. Sets `e` and frozensets `z` have a count followed by their sorted 16-byte element digests.
- A cycle is `@` followed by its unsigned 64-bit ancestor distance. Object identity and memory addresses are never encoded.
- Objects have `O`, the length-prefixed UTF-8 module-and-qualname identity, a field count and fields. Builtin subclass content and exception arguments precede slots. Member slots follow reverse MRO (base before derived), in each owner's class-dictionary order (the order of actual member descriptors); then instance-dictionary entries follow insertion order. A field has `p` for positional or `n` followed by a length-prefixed name, then `v` and its encoded value, or `u` for an unset member slot. Each unset slot consumes one walk node. Real member slots omitted by an edited declaration and their subtrees consume nodes as they are read. `__weakref__` and `__dict__` declarations are not slots. Replaced non-member descriptors are not invoked or read. An in-place change to `__slots__` does not hide an existing member descriptor. The existing preview reader still uses the declared slots. Only signature reading includes unset slots; previews and stored detail use the existing reader.
- Other supported kinds retain their existing structural information: classes use `C` and their length-prefixed identity, functions and builtin functions use `Y` and module/qualified name, decimal uses `D` and its canonical string, datetime/date/time and timedelta use `M` and subtype `D`/`d`/`T`/`t`. Dates encode year (u16), month and day (u8). Times encode hour, minute, second (u8) and microseconds (u32), followed by `n` for no UTC offset or `z` and the signed 64-bit offset in microseconds. Datetime combines date and time fields. Timedelta encodes signed 64-bit days and unsigned 32-bit seconds and microseconds. These preserve the information in the former ISO strings, including offsets and excluding `fold` unless it changes the offset. Range uses `R` followed by the three encoded integer components. Ellipsis is `E`, NotImplemented is `X`, unreadable partial values are `?` and the length-prefixed identity. Bound methods are `m`, their function value and length-prefixed receiver type. Partials are `P`, their function, arguments, a count of sorted keyword names and their name/value pairs.

Text payloads and object fields use the existing redaction policy. A secret stops the walk with `redacted`. Redaction decisions on values are evaluated by the existing policy. Value fingerprint caches invalidate when the policy changes. The walk charges every value it reads and each unset slot; its counts match v1 where it reads the same fields. Existing sketch triggering and sketch computation are retained.

Runs store `signature_version: 2` in their invocation. Missing versions mean v1. A previous recording with a different signature version is not used for comparison, and the run reports the mismatch.
