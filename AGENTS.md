# LDR Agent Entry Point

Before substantive work, read `docs/AGENT-CORE.md` completely and follow it.

In a fresh session, also follow the `start-session` command protocol before
substantive work. Repository commands for Codex are under `.agents/skills/`
and are invoked with the syntax the active Codex surface supports.

`docs/AGENT-CORE.md` is the shared authority for Codex and Claude Code. Do not
add Codex-specific product rules here.
